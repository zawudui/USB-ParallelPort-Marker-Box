# Manufacturing package

The hardware source and fabrication outputs are the r7.2 engineering prototype package.

Included manufacturing files are the r7.2 Gerber layers, PTH/NPTH drill files, assembly drawings, and a reference BOM by designator. The BOM is a design reference, not a locked vendor-SKU procurement list. Verify every exact manufacturer part number, package, polarity, footprint, lifecycle status, and sourcing substitution before ordering.

The r7.2 PCB manufacturing source is the reviewed source snapshot associated with the first EVT build. Do not regenerate fabrication outputs from a different KiCad working copy and assume they are identical. Compare source commit, Gerber, drill, BOM, and SHA-256 before fabrication.

The enclosure CAD in this release is a FIRST-FIT prototype. Connector hood, thumbscrew and cable clearance require physical test fitting.
