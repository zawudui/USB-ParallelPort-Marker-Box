# Enclosure CAD

## Selected design

The current selected mechanical concept is the **r7.2 C / PA12 screwless snap-fit enclosure**:

- [snap-fit-pa12/](r7.2/snap-fit-pa12/) — two-piece PA12 MJF/SLS shell with four integral, releasable snap latches; no screws or separate assembly hardware.
- The print package contains exactly two STL parts: base and lid.

## Historical / alternative designs

- [r7.2/first-fit/](r7.2/first-fit/) — earlier screw-fastened first-fit prototype. Retained for engineering history; it is not the selected screwless design.
- The 2026-11-05 A/B/C trial package is retained in the private engineering repository. Only the selected C / PA12 design is curated here.

## Validation status

The C design has CAD geometry and mesh checks, but its snap force, retention force, fatigue life, and exact cable-hood/jackscrew clearance still require physical verification. Use unfilled PA12 with MJF or SLS; FDM PLA/PETG and standard SLA resin are not qualified for this geometry.
